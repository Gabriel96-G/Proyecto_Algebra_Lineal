CONTEXTO GENERAL
------------------------------------------------------------------------------
Cada objeto 2D del proyecto se representa como una matriz P de tamaño 2xN:

    P = [ p1  p2  ...  pN ]

Cada columna p_i representa un punto del objeto:

    p_i = (x_i, y_i)^T

Las transformaciones de rotación, escalamiento y reflexión se aplican mediante
multiplicación matricial:

    P' = M * P

La traslación se aplica con coordenadas homogéneas porque no es una
transformación lineal pura en R².

================================================================================
1. ALGORITMO: TRASLADAR OBJETO
------------------------------------------------------------------------------
Propósito:
Mover todos los puntos de un objeto dx unidades en el eje x y dy unidades en el
eje y.

Entrada:
    objeto — instancia de Objeto2D con matriz de puntos 2xN
    dx     — desplazamiento horizontal
    dy     — desplazamiento vertical

Salida:
    objeto_transformado — nuevo Objeto2D trasladado
    matriz              — matriz homogénea 3x3 utilizada

Matriz utilizada:

        [1  0  dx]
    T = [0  1  dy]
        [0  0   1]

Algoritmo:
1.  Validar que el objeto recibido sea de tipo Objeto2D.
2.  Construir la matriz homogénea de traslación:
        T ← [[1, 0, dx],
             [0, 1, dy],
             [0, 0,  1]]
3.  Tomar la matriz de puntos P del objeto, con forma 2xN.
4.  Agregar una fila de unos para convertir los puntos a coordenadas homogéneas:
        Ph ← [P; 1]
5.  Multiplicar la matriz de traslación por los puntos homogéneos:
        P_h_transformado ← T * Ph
6.  Extraer las primeras dos filas del resultado:
        P_transformado ← primeras dos filas de P_h_transformado
7.  Crear un nuevo Objeto2D con P_transformado.
8.  Devolver objeto_transformado y T.

Ejemplo:
    Punto original:     (2, 3)
    dx = 4, dy = -1
    Punto transformado: (6, 2)

2. ALGORITMO: ROTAR OBJETO
------------------------------------------------------------------------------
Propósito:
Rotar todos los puntos de un objeto alrededor del origen usando un ángulo en
grados.

Entrada:
    objeto — instancia de Objeto2D con matriz de puntos 2xN
    angulo — ángulo de rotación en grados

Salida:
    objeto_transformado — nuevo Objeto2D rotado
    matriz              — matriz 2x2 de rotación utilizada

Matriz utilizada:

        [cos(theta)  -sen(theta)]
    R = [sen(theta)   cos(theta)]

Algoritmo:
1.  Validar que el objeto recibido sea de tipo Objeto2D.
2.  Convertir el ángulo de grados a radianes:
        theta ← angulo * pi / 180
3.  Calcular:
        c ← cos(theta)
        s ← sen(theta)
4.  Construir la matriz de rotación:
        R ← [[c, -s],
             [s,  c]]
5.  Multiplicar la matriz R por la matriz de puntos P:
        P_transformado ← R * P
6.  Crear un nuevo Objeto2D con P_transformado.
7.  Devolver objeto_transformado y R.

Ejemplo:
    Cuadrado con punto (2, 0)
    Rotación 45°:
    (2, 0) → (1.414, 1.414)

3. ALGORITMO: ESCALAR OBJETO
------------------------------------------------------------------------------
Propósito:
Cambiar el tamaño del objeto multiplicando las coordenadas x por sx y las
coordenadas y por sy.

Entrada:
    objeto — instancia de Objeto2D con matriz de puntos 2xN
    sx     — factor de escala horizontal
    sy     — factor de escala vertical

Salida:
    objeto_transformado — nuevo Objeto2D escalado
    matriz              — matriz diagonal 2x2 utilizada

Matriz utilizada:

        [sx  0 ]
    S = [0   sy]

Algoritmo:
1.  Validar que el objeto recibido sea de tipo Objeto2D.
2.  Si sy no fue indicado, asignar:
        sy ← sx
3.  Construir la matriz diagonal de escalamiento:
        S ← [[sx, 0],
             [0, sy]]
4.  Multiplicar S por la matriz de puntos P:
        P_transformado ← S * P
5.  Crear un nuevo Objeto2D con P_transformado.
6.  Devolver objeto_transformado y S.

Ejemplo:
    Punto original:     (2, 3)
    sx = 2, sy = 2
    Punto transformado: (4, 6)

4. ALGORITMO: REFLEJAR OBJETO
------------------------------------------------------------------------------
Propósito:
Reflejar un objeto respecto al eje x, eje y o la recta y=x.

Entrada:
    objeto — instancia de Objeto2D con matriz de puntos 2xN
    eje    — eje de reflexión: "x", "y" o "y=x"

Salida:
    objeto_transformado — nuevo Objeto2D reflejado
    matriz              — matriz 2x2 de reflexión utilizada

Matrices utilizadas:

Reflexión respecto al eje x:

        [1   0]
    F = [0  -1]

Reflexión respecto al eje y:

        [-1  0]
    F = [ 0  1]

Reflexión respecto a la recta y=x:

        [0  1]
    F = [1  0]

Algoritmo:
1.  Validar que el objeto recibido sea de tipo Objeto2D.
2.  Normalizar el texto del eje indicado.
3.  Si eje = "x":
        F ← [[1, 0], [0, -1]]
4.  Si eje = "y":
        F ← [[-1, 0], [0, 1]]
5.  Si eje = "y=x":
        F ← [[0, 1], [1, 0]]
6.  Si el eje no es válido, lanzar un error.
7.  Multiplicar F por la matriz de puntos P:
        P_transformado ← F * P
8.  Crear un nuevo Objeto2D con P_transformado.
9.  Devolver objeto_transformado y F.

Ejemplos:
    Reflexión eje x:   (2, 3) → (2, -3)
    Reflexión eje y:   (2, 3) → (-2, 3)
    Reflexión y = x:   (2, 3) → (3, 2)

5. ALGORITMO: TRANSFORMACIONES CONSECUTIVAS
------------------------------------------------------------------------------
Propósito:
Aplicar varias transformaciones en orden, simulando el comportamiento de un
motor gráfico real.

Ejemplo del proyecto:
    Rotar 30° → Escalar 1.5 → Trasladar

Algoritmo:
1.  Recibir el objeto original P.
2.  Aplicar rotación:
        P1, R ← rotar(P, 30)
3.  Aplicar escalamiento sobre el resultado anterior:
        P2, S ← escalar(P1, 1.5)
4.  Aplicar traslación sobre el resultado anterior:
        P3, T ← trasladar(P2, dx, dy)
5.  Mostrar todas las matrices utilizadas:
        R, S, T
6.  Para representar la composición completa en coordenadas homogéneas:
        R_h ← matriz R ampliada a 3x3
        S_h ← matriz S ampliada a 3x3
        T_h ← matriz T
7.  Calcular la matriz compuesta respetando el orden de aplicación:
        C ← T_h * S_h * R_h
8.  Devolver el objeto final P3 y la matriz compuesta C.

Nota:
El orden es importante. En general:

    T * S * R ≠ R * S * T
